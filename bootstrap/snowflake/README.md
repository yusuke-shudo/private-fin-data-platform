# Snowflake 初期ブートストラップ手順

CI/CD（GitHub Actions）を稼働させる前に、SnowflakeのWeb画面から手作業で実行する必要がある初期設定です。

## 1. 組織アカウントでの作業
1. 組織の管理アカウント（親DB）にログインします。
2. `01_org_admin_setup.sql` を開き、パスワード部分を書き換えて実行します。
3. これにより、子アカウント（`_dev`, `_prd`）が作成されます。

## 2. 子アカウントでの作業（DEV / PRD 共通）
作成された **DEVアカウント** および **PRDアカウント** のそれぞれにログインし、以下の手順を実行します。

1. 各アカウントの Worksheets を開きます。
2. `02_child_account_cicd_setup.sql` の内容をコピー＆ペーストします。
3. **重要**: SQL下部にある `SUBJECT` の `<ENVIRONMENT_NAME>` 部分を、実行しているアカウントに合わせて書き換えます。
   - DEVアカウントの場合: `dev`
   - PRDアカウントの場合: `prd`
4. SQLをすべて実行します。
