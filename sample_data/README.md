# Sample Data

- 日本語版: [README.ja.md](README.ja.md)

This directory contains sample files used to understand source data formats and validate transformation logic.

## Directory Structure

- paypay_bank/: PayPay Bank sample files (for home loan schedule use cases).
- sbi_securities/: SBI Securities sample files (for tokutei account profit/loss report use cases).

## Usage Notes

- Keep this dataset small and stable for reproducible testing.
- Do not commit sensitive or personally identifiable information.
- Use anonymized or masked values for public repository safety.
- Name sample files as table_name_sample.ext (for example: home_loan_schedule_raw_sample.csv).
